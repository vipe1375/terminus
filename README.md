# Untitled Metro Game

Chaque jour, une carte s'affiche avec un marqueur qui indique une station du métro parisien. Le but du jeu est de deviner de quelle station il s'agit, en s'aidant (ou non) des indices. Un indice ou une mauvaise tentative coûte des points.

Jouable [ici](https://untitled-metro-game.onrender.com/)
